Site Maintenance

Content Editor

A static GitHub Pages site cannot save changes directly online, but this helper lets you edit the data file and download an updated copy.

How this works

  1. Use the forms below to add an event or downloadable form.
  2. Click “Validate JSON.”
  3. Click “Download site-data.json.”
  4. Replace data/site-data.json in your GitHub repo.

To add new PDFs, upload them into the downloads folder and use a URL like downloads/my-form.pdf.

Choose an existing event, make changes, then download the updated JSON file. The calendar and list view both update from this same event data.

Use this section to replace downloadable PDFs, rename forms, update deadlines, or mark forms as coming soon.

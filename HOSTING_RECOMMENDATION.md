# Hosting Recommendation

## Best option for this project: CloudCannon

For this specific customer, CloudCannon is the best next step because the customer can edit the page visually instead of opening GitHub or touching HTML. It also works directly with a GitHub repository, so Jon can still keep version control and make developer updates when needed.

## Why not GitHub Pages only?

GitHub Pages is good for free static hosting, but it does not include:

- A client-friendly page editor
- A form inbox
- Easy image/content management for a non-technical customer
- User permissions for a business owner/editor

## Lower-cost alternative

Netlify + Decap CMS can work, especially if budget is the biggest concern. It keeps the site static and gives an `/admin` editor, but it is less visual and may require more setup for authentication. Netlify Forms are strong for a simple contact form.

## Most client-friendly alternative

Wix or Squarespace would be easiest for a business owner, but you would be rebuilding the site inside their platform and giving up more control over the custom static site files.

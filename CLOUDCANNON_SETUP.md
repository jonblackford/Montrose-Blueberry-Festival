# CloudCannon Setup Guide

## Best setup for this client

Use **CloudCannon hosting + GitHub sync** for this project. That gives the customer a visual editor, keeps the files in GitHub, and provides a form inbox without needing custom backend code.

## Steps

1. Create or open the `His-Herbs` repository on GitHub.
2. Upload the contents of this folder to the root of the repository.
3. Create a CloudCannon account.
4. Add a new site in CloudCannon and connect it to the GitHub repo.
5. Use the default branch, usually `main`.
6. Set the site type/build as a static site. No build command is needed.
7. Use CloudCannon hosting for the live site if you want CloudCannon Forms.
8. Invite the customer as an editor.
9. In the Visual Editor, they can click editable page sections to update text and images.

## Why CloudCannon

GitHub Pages is fine for basic hosting, but it does not give the customer a simple editing dashboard or a form inbox. CloudCannon is better when the business owner needs to change wording, seasonal highlights, photos, and contact information without touching code.

## Editable areas already prepared

The homepage has CloudCannon source editable regions for:

- Hero section
- About section
- Services section
- Seasons section
- Gallery section
- Visit/contact information
- Contact form intro text
- Final call-to-action section

## Important note

The customer should edit wording and images, but should avoid deleting form fields unless they are comfortable with testing the form again afterward.

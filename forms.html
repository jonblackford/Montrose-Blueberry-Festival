How to replace a downloadable form

1

Add the file

Put the new PDF, image, or document in the downloads folder.

2

Update the link

Open data/site-data.json and change the form's url to something like downloads/parade-2027.pdf.

3

Commit to GitHub

Commit the changed data file and new download. GitHub Pages will publish the update automatically.
